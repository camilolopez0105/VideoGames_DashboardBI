# VideoGames Dashboard BI

Power BI dashboard for video game data analysis and visualization.

## Overview

Interactive Business Intelligence dashboard built with Microsoft Power BI for exploring and analyzing video game datasets.

## Features

- Interactive data visualizations
- Video game metrics and statistics
- Business intelligence reporting

## Requirements

- Microsoft Power BI Desktop (latest version)
- Video game dataset (included in the .pbix file)

## Usage

1. Open `ForRealVGProject.pbix` in Power BI Desktop
2. Explore the dashboards and visualizations
3. Use filters and slicers for detailed analysis
